1. Summary

Feather converts documents into Markdown entirely inside your browser. Your files are never uploaded, because the extension has no server to upload them to. The only data that leaves your browser is a small set of anonymous, non-identifying usage counts described in section 4, plus any request you deliberately trigger by adding your own AI provider key as described in section 6.

In one line: we do not receive your documents, your filenames, your converted Markdown, or your conversations. We receive counts.

2. Who is responsible

Feather is published by Quilonix, which is the data controller for the limited processing described here. You can reach us at contact@quilonix.in for any privacy question or request.

3. What we never collect

The following never leaves your browser and is never transmitted to us or to any third party by the extension:

  • The contents of any file you convert.
  • Filenames, file paths, or file metadata.
  • The Markdown that Feather produces.
  • Images or figures extracted from your documents.
  • The text of any chat conversation you extract.
  • Your name, email address, IP-based profile, or any account identifier. Feather has no accounts and no sign-in.
  • Anything from web pages other than the supported AI chat sites listed in the extension's manifest. Feather does not run on any other page.

Document parsing, table detection, image extraction and OCR all run as WebAssembly and JavaScript inside the tab you are already on.

4. What we do collect

Feather sends anonymous usage events so we can tell how many people install it and whether they keep using it. Events are sent by a direct HTTPS request to PostHog Cloud (EU region). No remote script is loaded.

Each event carries a random identifier generated once on your device with crypto.randomUUID() and stored locally. It is not derived from your hardware, your browser fingerprint, your IP address, or any account. It is not linked to any identity, and we cannot use it to contact you or recognise you anywhere else.

The complete list of events

Event When Properties sent
extension_installed Once, on first install none
extension_active At most once per calendar day, when the widget loads on a supported site hostname
file_converted A file finished converting fileExtension, tokenSavingsPercent, imagesExtracted, hostname
file_conversion_failed A file could not be converted fileExtension
chat_extracted Extract Chat pulled a conversation hostname
chat_summarized The optional AI pass on a chat finished hostname, tokenSavingsPercent

hostname is the site the action happened on, for example chatgpt.com. It is never the full URL, never a page title, and never any part of the page content. fileExtension is a type such as pdf. tokenSavingsPercent and imagesExtracted are numbers. That is the entire payload.

The purpose is aggregate product measurement: install counts, daily and monthly active counts, which formats are actually used, and whether conversion is failing. Our legal basis under the GDPR is legitimate interest in understanding and maintaining the product, using the least identifying data that serves that purpose.

5. Data kept on your device

The following is stored by the extension on your own machine and is not sent to us.

  • Settings in chrome.storage.sync: your theme choice, whether Feather is disabled globally or on specific sites, and which AI mode you picked. Because this uses Chrome's sync storage, Google may replicate it across Chrome profiles you are signed into, under Google's own privacy policy.
  • Your API key, if you add one, in chrome.storage.local. Local storage is deliberately used instead of sync storage so a pasted key does not leave the device it was typed into. It is stored unencrypted, because Chrome extension storage has no encryption at rest. Do not use a key you would not want readable by something else with access to this profile.
  • The anonymous identifier and the date of the last daily-active event, in chrome.storage.local.
  • The widget's position on screen, in the page's localStorage, so it stays where you dragged it.

Uninstalling the extension removes all of it. Clearing site data for a given site removes the stored widget position for that site.

6. Optional AI providers

Feather works fully without any API key. If you choose to enable the optional compression pass, you supply your own key for either Groq or Google Gemini. In that case, and only in that case:

  • The already-converted Markdown is sent directly from your browser to the provider you chose, authenticated with your key.
  • It is not routed through any server of ours. We never see the content, and we never see your key.
  • That provider's own privacy policy and data handling apply to those requests. Review Groq's policy or Google's Gemini API terms before enabling it.
  • You can remove the key at any time from the extension's settings, which returns Feather to fully local operation.

This feature is off unless you turn it on and paste a key.

7. Permissions and why each is needed

  • storage - saves the settings and the optional API key described in section 5.
  • activeTab and tabs - reads the current tab's hostname so the toolbar popup can tell whether you are on a supported AI site and offer a per-site on/off toggle. It is not used to read page content or browsing history.
  • Host permissions for the listed AI chat sites - injects the converter widget into those pages and inserts the converted Markdown into the site's own chat input. Feather runs on no other site.
  • eu.i.posthog.com - sends the anonymous events in section 4.
  • api.groq.com and generativelanguage.googleapis.com - used only if you supply your own key, as described in section 6.

Feather requests no other permissions. It does not use the downloads, scripting, history, cookies, or webRequest permissions.

8. Third parties and international transfers

  • PostHog processes the anonymous events on our behalf. We use PostHog Cloud's EU region, so those events are ingested and stored in the European Union.
  • Groq and Google receive content only if you enable the optional pass with your own key, as your own API usage.
  • GitHub hosts this website. If you visit it, GitHub processes standard request data such as your IP address for security and abuse prevention, under GitHub's privacy statement. We do not add analytics to this website.
  • Google distributes the extension through the Chrome Web Store. Installs, ratings and reviews are handled by Google under its own terms, and we receive only the aggregate figures the store shows any developer.

We do not sell personal data, we do not share it with advertisers, we do not run ad or affiliate networks, and we do not track you across sites.

9. Retention

Anonymous events are retained in PostHog only as long as they are useful for aggregate product measurement, and are reviewed periodically. Because the events contain no identifiers beyond a random per-browser value and no content, retaining them does not accumulate a profile of any individual. Data on your device stays until you remove the extension or clear it yourself.

10. Your rights

Depending on where you live, you may have rights to access, correction, deletion, restriction, objection, or portability of personal data, and the right to complain to a supervisory authority.

We should be straightforward about a limitation here: because the analytics identifier is a random value with nothing linking it to you, we generally cannot locate "your" events on request. If you want your identifier's events deleted, you can find it in the extension's local storage under fdDistinctId and send it to us, and we will delete events matching it. Otherwise, the most complete and immediate remedy is section 11, which stops collection entirely.

11. How to stop collection

  • Disable Feather from the toolbar popup, either globally or per site. The widget then does not load, so no usage events are sent.
  • Uninstall the extension from chrome://extensions. This stops all events and deletes everything stored on your device.
  • Block the endpoint at the network level if you prefer. The extension is built so that analytics failures are swallowed and never affect conversion, so blocking it does not break anything.

12. Security

All network requests the extension makes use HTTPS. The extension ships no remotely-hosted code, which is both a Chrome requirement and a deliberate choice: everything that runs is inside the package you install. The package distributed through the Chrome Web Store is reviewed by Google and signed with a key held by the store, so the copy Chrome installs is verifiably the copy we submitted.

No system is perfectly secure. If you find a vulnerability, please report it privately to contact@quilonix.in rather than opening a public issue.

13. Children

Feather is a productivity tool for general audiences and is not directed at children. We do not knowingly collect personal data from children, and the extension collects no personal data from anyone.

14. This website

This site is a static page. It sets no cookies, loads no web fonts, embeds no third-party scripts, and runs no analytics. The only requests it makes are for its own HTML and CSS. Your hosting-level request data is handled by GitHub as described in section 8.

15. Changes

If this policy changes, the effective date at the top of this page changes with it. If a change materially expands what we collect, we will say so in the extension's release notes on the Chrome Web Store rather than changing it quietly.

16. Contact

Questions, requests, or corrections: contact@quilonix.in.
