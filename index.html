01

Why a PDF costs more than it should

Some tools ingest a PDF by rasterizing every page into an image for a vision encoder rather than extracting the text. That costs tokens by page area, not by how much text is actually on the page, so a mostly-empty 100-page document can cost as much as a dense one.

Feather extracts the real text, detects tables from column positions, pulls embedded images out as real files, and runs OCR only on the pages that genuinely need it. You hand the model clean Markdown instead of pictures of paper.

02

How it works

Click the pill, or drag files onto it

A small pill sits in the bottom-right corner of every supported site. Drag it anywhere you like; it stays there. Drop up to five files at once.

Conversion runs in the page

pdf.js, mammoth, SheetJS and Tesseract OCR all run as WebAssembly and JavaScript inside the tab. No request is made, because there is nowhere to send it.

Attach or download

Attach puts the Markdown straight into the site's chat input. Download saves the file, or a zip containing the Markdown plus every extracted image when the document had figures.

03

Move a conversation to another model

A chat is trapped in the tool you started it in. When you want a second opinion from a different model, or you have hit a context limit and need a fresh thread, the usual answer is scrolling and copy-pasting turn by turn. Extract Chat lifts the whole conversation out as Markdown in one click.

Step one

Copied before you can lose it

The transcript lands on your clipboard the moment it is extracted, before anything else runs. Nothing to click first, and nothing to lose if a later step fails.

Step two, option A

Continue on another AI

Pick a destination and Feather opens it and attaches the transcript for you. Claude, ChatGPT, Gemini, Perplexity, Grok, DeepSeek, Mistral and Meta AI. If the attach does not take, the text is already on your clipboard and shown in the panel to paste.

Step two, option B

Download it as Markdown

Save the conversation as a .md file for your notes, an issue tracker, a commit message, or anywhere else plain text belongs.

Optional

Condense it first

With your own API key, a second pass summarizes the transcript instead of reproducing it: settled decisions, final answers and load-bearing facts, without the back-and-forth that got there.

Structure survives the trip. Code blocks stay fenced, lists stay lists, and who said what is preserved. Extraction works on sites with no hand-written adapter too, by detecting the repeated structure of the conversation rather than relying on a known selector.

It reads what the page has actually rendered. On a very long conversation, some sites only keep recent turns in the document, so scroll up to load the earlier ones before extracting.

05

What leaves your browser

Never sent

Your documents

File contents, filenames, and the converted Markdown never leave the tab. There is no backend, no storage bucket, and no upload endpoint anywhere in the extension.

Never sent

Your conversations

Extract Chat reads the page you are on and writes the result to your clipboard and the panel. The text of the conversation is not transmitted.

Sent

Anonymous counts

A random ID, which site a conversion happened on, the file extension, and a token-savings percentage. That is the entire payload. No content, ever.

Only if you opt in

Your own API calls

If you add your own Gemini key for the optional AI pass, the Markdown goes to that provider under your key. It never reaches us. The key is stored on your device only.

Full detail, including the exact event list and the third parties involved, is in the privacy policy.

06

Optional: bring your own key

Optional / off by default

Local conversion already works with zero setup and no key. If you want a second pass that compresses the Markdown further, you can add your own Gemini key. It has a free tier.

The two passes are deliberately different. On a document, the prompt is lossless: keep every fact, table, number and named entity, and remove only genuine boilerplate. On a chat transcript, it is allowed to summarize, because most of a transcript's length is not load-bearing once you have the outcome.

It fails safe. If the pass fails, you still get the local result. Feather never produces nothing because an optional step did not work.

07

What it does not do

Every tool has edges. Publishing them is cheaper than having you find them.

  • Legacy .doc and .ppt are not supported. No reliable client-side parser exists for them.
  • PDF table detection is heuristic. It handles clean grid tables well and can misjudge unusual layouts.
  • Diagrams drawn as vector paths are not extracted as images. Capturing them would require rasterizing the page, which defeats the purpose.
  • OCR adds real time on scan-heavy PDFs. It only runs on pages that need it, but a fully scanned 100-page document still takes a while.
  • To bypass strict Content Security Policies on sites like Gemini, the PDF parser is bundled directly in and runs synchronously on the main thread. This guarantees it works everywhere, but trades a roughly 1MB larger bundle size and freezes the tab while a PDF is actively parsing.
  • Hand-written attach adapters exist for three sites. Everywhere else uses generic strategies that work on many sites but are not verified per site, and fall back to download plus clipboard.
  • Extracting a chat reads what the page has rendered. On a very long conversation, some sites keep only recent turns in the document, so scroll up to load the earlier ones first.
  • There is no single guaranteed token-savings number. See the footnotes above.
